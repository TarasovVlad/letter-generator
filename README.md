# Генератор деловых писем

Веб-приложение для быстрого создания шаблонных деловых писем.

## Возможности

- 5 шаблонов писем: Отгул, Коммерческое предложение, Сопроводительное письмо, Претензия, Приглашение
- Автоподстановка реквизитов пользователя
- Предварительный просмотр письма в реальном времени
- Подсветка канцеляризмов и длинных предложений
- Подсказки по стилю для каждого типа письма
- Проверка ключевых фраз
- Сохранение реквизитов в localStorage
- Экспорт готового письма в формат .docx

## Стек

- HTML5, CSS3
- JavaScript ES6+ (без фреймворков)
- Библиотека [docx](https://docx.js.org/) — генерация .docx файлов

## Установка и запуск

```bash
git clone https://github.com/TarasovVlad/letter-generator
cd letter-generator
make install
make start
```

Открой браузер и перейди по адресу `http://localhost:3000`

## Структура проекта
```
letter-generator/
├── index.html        - разметка приложения
├── style.css         - стили и адаптивность
├── js/
│   ├── data.js       - шаблоны писем и профиль пользователя
│   ├── templates.js  - поиск шаблона и сборка письма
│   ├── validation.js - проверка стиля и подсветка проблем
│   ├── export.js     - генерация и скачивание .docx
│   └── app.js        - точка входа, обработчики событий
├── Makefile          - команды запуска и линтинга
└── package.json      - зависимости проекта
```
